# Simple — Private Encrypted Messenger for Android (`v7.0.0`)

**Created by Dr. M Verma**

Simple is a privacy-first, end-to-end encrypted (E2EE) native Android messaging, HD voice/video calling, and 24-hour status application.

---

## Direct Android `.apk` Download & Installation (`v7.0.0` & `v6.0.0`)

This repository includes the ready-to-install, cryptographically signed (JAR v1 + APK Signature Scheme v2) native Android `.apk` files directly in the repository root and in `releases/`:

- **[`Simple-Android-v7.0.0.apk`](./Simple-Android-v7.0.0.apk)** (Repository Root — Latest Versioned `v7.0.0` APK)
- **[`Simple-Android-v6.0.0.apk`](./Simple-Android-v6.0.0.apk)** (Repository Root — Versioned `v6.0.0` APK)
- **[`releases/Simple-v7.0.0.apk`](./releases/Simple-v7.0.0.apk)** (`releases/` Folder — Latest `v7.0.0` APK)
- **[`releases/Simple-v6.0.0.apk`](./releases/Simple-v6.0.0.apk)** (`releases/` Folder — `v6.0.0` APK)
- **[`Simple-Android.apk`](./Simple-Android.apk)** (Repository Root — Direct Latest APK Alias)

### How to Download & Install on Your Android Phone:
1. Tap **[`Simple-Android-v7.0.0.apk`](./Simple-Android-v7.0.0.apk)** (or **[`Simple-Android-v6.0.0.apk`](./Simple-Android-v6.0.0.apk)**) directly in this GitHub repository.
2. Tap **Download raw file** (or the `⋯` menu → **Download** on GitHub Mobile).
3. Open the downloaded `.apk` file on your phone and tap **Install** (allow *Install unknown apps* if prompted by Android).
4. Launch **Simple** from your Android App Drawer (`com.drmverma.simple`).

---

## Rebuilding the Android `.apk` Locally

```bash
npm install --legacy-peer-deps
npm run build:apk
```
